# GOALSROLLS — Gestão de Rotina e Produtividade

Aplicação web personalizável voltada para organização pessoal e foco diário. O sistema reúne calendário, cronômetro Pomodoro e alternância de temas em uma interface adaptável à rotina de cada usuário.

**Demo no ar:** https://caracamoleque.lovable.app/ 

## Funcionalidades
- **Gestão de Rotina e Calendário:** organização visual de tarefas, compromissos e acompanhamento diário.
- **Timer Pomodoro:** cronômetro integrado para ciclos de foco e pausas programadas.
- **Interface Personalizável:** alternância de temas (claro/escuro) e ajustes visuais de acordo com a preferência do usuário.

## Stack utilizada
- React
- TypeScript
- Vite
